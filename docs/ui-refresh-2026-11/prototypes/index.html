Rules (proposed)
  1. Raised = the sheet, the bar in a pill view, or the keyboard up.
  2. While raised, the first touch outside lowers it to the view's resting form and reaches nothing.
  3. Only the dock opens the chat: tap the Alpha mark, or drag up from the bar or pill.
  4. Back unwinds one level: keyboard → full → sheet → raised bar → the view.
  5. Lowering never discards a draft.
