## Unmodeled state machines (first pass)


1. **Cloud Maps connection and retry** (`maps/cloud-maps.ts:13-55`, `maps/cloud-provider.ts:70-148`). State: `pending`, `retry` timer, `retries`, `lastAttempt`, `generation`, `installed`, diagnostic. Events: account change, online, visible, timer, attempt settle, retire. Invariants at risk: liveness (C3) and "reconnect never uninstalls a healthy provider under guidance" (C1).
2. **Guidance session** (`maps-adapter.ts:62-69, 83-88, 210-267`). Flags: `navigating`, `rerouting`, `rerouteCleared`, `offRoute`, `arrived`, `navStep`, `navSession`, `rerouteTimer`/`rerouteAttempts`, `backgroundRunning`, `follow`. Invariants: `rerouting ⇒ navigating`; timer set ⇒ navigating and not arrived; `navRoute` defined iff navigating; stale `navSession` callbacks are inert.
3. **BackgroundNavigation** (`maps/background-navigation.ts`). States: none, starting, active, stopped. There is no explicit "starting" state (C4).
4. **NativeMapsLocation** (shared `native-location.ts`). State: `admitting`, `generation`, session, `requestingPermission`, foreground wait. `start()` rejects while admitting (C2).
5. **Maps screen modes** (`maps-adapter.ts:388`): base, results, place, dir, origin, nav. Driven by `searching`, `selected`, `directions`, `originMode`, `locating`, `searchIntent`, `pendingHandoff`, `chosenOrigin` and the "late fix" restore (173-177).
6. **Chat auto-open** (`prototype/maps-chat-adapter.ts:29-36, 57`). `Seen{ids,last,fresh}`. Invariant: each reply opens at most once; restored or replaced history never opens; direct start only for a fresh reply.
7. **Browser tab and native-surface lifecycle** (`browser-adapter.ts:163-218`). `created` promise map, `restored`, `restoreAttempts`, `metadata.sequence`, `documentRevisions`, `profileUnsupportedTab`. Surface visibility is a 14-term predicate (474).
8. **Session persistence** (304-329): `sessionRead`, `sessionHydrated`, `lastSaved`, `saveQueue`, `clearingData`.
9. **Bookmarks hydration and recovery** (53-80): `bookmarkRead`, `bookmarkHydrated`, `bookmarkRefreshQueued`, `bookmarkRecovery`.
10. **Find in page** (225-251, 432-436): `finding`, `findTab`, debounce timer, native `cleared` event. Invariant: `finding ⇒ findTab == cur`. Tab pick and close (401) do not clear it; the renderer relies on a native event.
11. **Review dialogs:** `BrowserReviews` (`browser/review.ts:5-41`), `reviewContentQuestion`, `reviewBrowserReading`, `openSelectedDocumentViewer`. Invariant: approval only when foreground and unlocked at click; settle once; listeners removed.
12. **Web `BrowserSurface` per-tab navigation** (`browser/browser-surface.ts:29-48`): `loading`, `committed`, `error`, `navigation`, frame identity.
13. **Dev password-provider dialog** (`browser/password-provider.ts:14-40`): opening abort, `closed`/`busy`/`unlocked`, revision CAS.
14. **Private-tab egress:** bookmark (400), email share (266-271), Ask (124). Only `openExternalBrowser` has a private review (281-286).

## Modeling opportunities (first pass)


**New Quint modules**
- **`MapsConnection`:** the retry machine from B1. Liveness: transient error ∧ signed in ∧ eventually foreground ⇝ a retry is scheduled or pending. Safety: a reconnect while guidance is active does not uninstall the provider.
- **`GuidanceSession`:** B2 and B3 together. Invariants: `BackgroundStartedBeforeUpdate`, `StartHasLocationOrError`, `ArrivedLatches`, `RetryTimerImpliesNavigating`, `StaleSessionCallbacksInert`.
- **`BrowserSession` extensions:** `SavedTabsSurviveLateRestore`, `TabsBounded` (≤ 8 across all creation paths), `HistoryOnlyFromCommitted`, plus `closeNormal` and `clearData` actions.
- **`CredentialVault` extensions:** `EntriesImplyActiveForeground`, `LockFencesRefresh`; make `background` clear `resetAuthorized`.
- **`BrowserReadingState`:** clear `sensitive` on navigation; add the empty-excerpt fallback.
- **`ChatMapsAutoOpen`:** at-most-once open per reply; history replace never opens.
- **`FindInPage`:** `finding ⇒ findTab == cur`.

**Pure functions for function-level verification**
- **`normalizeBrowsing`, `browsingSnapshot`, `restoreBrowsing`** (`browser/browsing-session.ts`): idempotence; bounds 8/100/200; no duplicates; `cur ∈ tabs ∨ ''`; no private tab in output; non-pristine restore leaves tabs unchanged; visits are a superset of the input, capped at 100.
- **`savedBrowserUrl`:** true implies http(s), no credentials, length ≤ 4096.
- **Address classifier** (inline at `browser-adapter.ts:170-182`; extract it): total function to exactly one of URL, search or reject; any input containing whitespace is never a URL.
- **`usableNavigationFix`** (`maps/navigation-fix.ts:5`): monotone in `now`; false for a future timestamp beyond 5 s or non-precise.
- **`distanceToRoute`, `routeProgress`** (shared `route-distance.ts`): result ≥ 0; zero on a vertex; `alongMeters ∈ [0,total]`; `maneuverAlongMeters` non-decreasing; `remainingMeters + alongMeters = total`.
- **`atStep`, `guidanceDistance`, `guidanceDuration`** (`maps/guidance.ts`): distance ≥ 0; rounding buckets; minutes ≥ 1.
- **`insideCloudCoverage`, `validBounds`** (`maps/cloud-provider.ts:16-25`).
- **`cloudMapsFailure`, `deviceNavigationFailure`:** total mapping onto the code enums. Note that `device-navigation.ts:102,104` classifies by regex on message text, which is brittle.
- **`sensitiveReadingUrl`, `sensitiveReadingText`:** fail closed on malformed input; adding text never unblocks. `sensitiveReadingDocument` runs before nav/header stripping (`browser/reading-source.ts:18`), so any "Sign in" link blocks the page.
