## Unmodeled state machines (first pass)


1. **Notes draft slot** (`R/notes-secure-store.ts:29-127`): none, kept (failed, uncertain, storage-full), merged, applied, cleared, with three CAS retries. At risk: an older unsaved edit lost or resurrected.
2. **Trash UI and maintenance** (`P/notes-trash-adapter.ts:28-63`, `:220-270`): `busy`, single-flight `maintaining`, `refused`, `trashConfirm`, `trashFull`, `trashOpen`, 15-minute timer. At risk: permanent delete of a changed note.
3. **Deletion claims and lease** (`R/permanent-voice-deletion.ts:73-110`): the Web Lock claim map is only abstracted as `claimedElsewhere`.
4. **Scan text review** (`P/scan-review.ts:25-52`): OCR starting, ready or failed; `attempted` latch; `pdfAttempted` with retry; `keeping`; nested document dialog.
5. **Searchable review** (`P/scan-searchable-review.ts:14-27`): recognising, ready, busy, then cancelled, exported or unconfirmed.
6. **Scan correction** (`P/scan-correction-review.ts:12-28`): corners, busy, preview, apply.
7. **System picker counter and file picker** (`P/scan-pdf.ts:23-28`, `B/file-picker.ts:1-8`): global `systemPickers` gates every hide-means-close rule. At risk: a dialog surviving a real background.
8. **Share panel** (`R/share-panel.ts:6-41`): singleton, 250 ms `current()` watch, retirement events.
