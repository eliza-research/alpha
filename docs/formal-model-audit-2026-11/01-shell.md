## Unmodeled state machines (first pass)


1. **Native Back gate.** `dataset.alphaCanGoBack` (`agent-adapter.ts:118-121`) feeds `MainActivity.java:323-333`, which picks alpha-back, launcher-home or `finish()`. Invariant: the flag is true exactly when `back()` would change state.
2. **Shell screen/secure machine.** `screen` is boot/lock/off/home, crossed with `secure` and `voice` off/listening/thinking/speaking, driven by timer groups `G`/`I` (`model.js:5218-5221`, `5310-5330`, `5531-5562`). Invariant: no view while locked; timers cleared on leave.
3. **Launcher inventory** (`home-launcher.ts:132-254`). `status` idle/loading/ready/failed, `launching`, `generation`, three migration flags, 120 ms debounce (`273-276`). Invariant: no stale inventory shown; an explicit favourite choice beats the default write; `launching` always clears.
4. **Chat drag machine** (`chat-overlay-motion-adapter.ts`). `chatMotion` with `moved`/`flick`, `dockComposerFocused`, `dockGuardPress`, `chatScrimPress`, `swallow`/`chatDraggedAt` 350 ms windows. Invariant: one gesture yields at most one mode change; no click-through.
5. **Two independent keyboard detectors.** `keyboardFreeHeight` (`canvas-geometry.ts:51`) and `dockKeyboardWatch` (`chat-overlay…:186-196`, 150 px threshold). They can disagree.
6. **Flow/refresh interleaving in the walkthrough.** `pending`/`generation` per flow versus the component's `sequence`/`actionPending`/`alive`/`completedReady`/`reopened`/`target`. The model has one ticket; superseded-refresh `null` results are unmodeled (see C1).
7. **Inline-modal and inert ownership.** `holdPhoneInert` refcount (`modal-inert.ts`), `createInlineModal` mount/dispose (`inline-modal.ts:4-59`), `subviewFocus`/`reviewFocus` opener restore (`subview-accessibility.ts:72-108`). Invariant: inert is released exactly once; focus never lands in an inert subtree.
8. **Shade pull.** `installOverflowPull` start/claimed (`system-shade.ts:135-172`) and the `alphaShadeAsking` in-flight flag (`215-224`).
9. **Settings async guards.** `generation`, `scaleGeneration`, `listenerSequence`, `capabilityAbort`, `inferenceAbort` and six busy flags (`settings-adapter.ts:175-322`); licences idle/loading/ready/unavailable (`:51-65`).
10. **Dynamic view admission.** `refreshImage` mutates `ORDER` and the enabled/deferred sets on every resume (`main.tsx:303-306`, `mvp-features.ts:43`).
11. **Dock-clearance publisher** (`dock-clearance.ts:36-102`). rAF plus three observers; the last footprint is retained while no dock is visible.

## Modeling opportunities (first pass)


**New Quint modules or extensions**
- **BackDispatch:** native gate × renderer layers (popover, dialog, inline modal, drawer, voice, chat, view stack). Invariants: `canGoBack` iff `back()` is not a no-op; Back closes the topmost z-order layer. Would catch C3 and C5.
- **ShellNavigation:** add a `navigateOwn` step between claim and acknowledge that bumps the revision; add `unknown`, `hidden` chat, stack and secure.
- **PermissionWalkthrough:** add overlapping refreshes with `null` results, `reopenAll` (completed to pending), reopen while signed out, and an `attempted`-write failure. Invariants: progress regresses only to a key whose platform state is not ready (C1); every reachable modal state has an exit or a grant path (C2).
- **LauncherInventory:** generation-fenced load, migration flags, launch in flight.
- **ChatDock:** gesture/guard machine. One mode change per pointer sequence; the Rest(view) invariant including (home, hidden).
- **KeyboardGeometry:** the estimator as state, with a keyboard-during-rotation or resize scenario. Property: portrait window plus keyboard never yields `landscape`.

**Pure functions for pre/postcondition verification**
- `chatRelease` (`chat-overlay-motion-adapter.ts:49`): result is one of hidden/sheet/full; `height` only with sheet and strictly between the floor and top zones; flick ignores height.
- `restingHeight` (same file): result ≤ full; ≥ min(200, half) when `share` is set.
- `releaseVelocity` (same file): returns 0 after an 80 ms hold.
- `keyboardFreeHeight` and `canvasGeometry` (`canvas-geometry.ts:51`, `64`): same width while editing gives a non-decreasing base; `scale > 0`; `wide` iff `width/scale ≥ 760`.
- `surfaceLayout` (`:103`): `1 ≤ calendarDays ≤ 7`; agenda implies no split and one day.
- `emptyHomeShadePull` and `overflowPullDecision` (`system-shade.ts:65`, `86`): monotone in guards; `claim` implies `dy > |dx|`.
- `readStartupPermissionProgress` and `writeStartupPermissionProgress` (`startup-permission-progress.ts:7`, `22`): round-trip; completed implies step equals the version's count.
- `createStartupPermissionFlow` with a fake bridge: at most one `request()` per key.
- `filterLauncherApps`, `describeLauncherApps`, `appKey` (`home-launcher.ts:35-89`): output is a subset; rows with distinct keys never share label plus details.
- `cleanKeys` and `moveFavorite` (`home-launcher.ts:100`, `243`): result is unique and a permutation.
- `settingsPage` (`settings-adapter.ts:126`): closed over `SETTINGS_PAGES`.
- `calendarCardState`, `presentHomeAttention`, `attendeeInitials` (`home-cards.ts:160`, `27`, `202`): total; at most 3 chips.
- `folderScopeCurrent`, `createFolderRevisions`, `captureUnchanged` (`context-selection.ts:57-183`): LRU bound; revision changes iff signature changes.
- `handoffGate` (`native-adapter.ts:119`): never two `begin` results of true inside the window.
