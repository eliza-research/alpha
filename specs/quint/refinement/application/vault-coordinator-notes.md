# Vault coordinator refinement

The driver executes `passwordManagerGroups`, `passwordEntryPage`, returned input callbacks and the real lifecycle handlers. Its shared `PasswordsClient` uses controlled native ports. Four schedules record 24 checkpoints for typed-secret retirement, backgrounding, damaged-vault review and a pending authentication result after leaving.

A Boolean represents whether the editor contains a secret. The receipt excludes the synthetic secret text. Leaving advances the source generation and clears the editor and reset review. A late native operation can finish without reviving that review. Android authentication, encrypted storage and actual autofill remain platform obligations.
