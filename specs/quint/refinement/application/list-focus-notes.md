# List-focus source refinement

`ListFocus` executes `createKeyedListFocus` with real JSDOM focus events and source microtasks. Twenty-four schedules cover two capture slots, two roots, duplicate or removed identities, hidden and disabled nodes, navigation, discarded renders and a newer committed render. Visibility geometry is a controlled JSDOM input.

The Alpha bindings use semantic note IDs across pinned and unpinned lists and media IDs across virtual Photos sections. Existing grid viewport refs remain active. The helper cannot restore focus after a user moves it, after its capture expires, or onto an ambiguous or unavailable item.

Browser tests separately exercise the actual renderer. The current Files volume adapter exposes volume/path, category, breadcrumb, destination and sort identities through an authenticated shared-source patch. `InstalledAppsGridDrawer` already keys app rows by package identity. Historical local Files and launcher components are retained only in Git history.
