# App

The phone's interface: Home, the built-in apps and Ask Alpha, as one page
that Android shows as the launcher. Each area keeps its own state and
rules.

- [Shell](./shell/): where the owner is, and the layers over it
- [Startup](./startup/): how Alpha comes up, asks for access and recovers
- [Home](./home/): the launcher, its tiles and the cards
- [Assistant](./assistant/): Ask Alpha, its conversation, composer and cards
- [Voice](./voice/): voice sessions, listening, speech recognition and spoken turns
- [Browser](./browser/): tabs, navigation, bookmarks, downloads and agent browsing
- [Digests](./digests/): scheduled digest inbox and delivered summaries
- [Notices](./notices/): in-app alerts, unread counts and dismissal
- [Approvals](./approvals/): owner review of agent proposals and leases
- [Control](./control/): external app observation, bounded agent actuation leases, protected-screen refusal and kill-switch
- [Passwords](./passwords/): stored credentials and vault entries
- [Workflows](./workflows/): scheduled and on-demand workflows, runs and hosted results
- [Settings](./settings/): the phone's facts, preferences, agent activity and reset
- [Inbox](./inbox/): Gmail's list, a message, drafts and the agent's operations
- [Telegram](./telegram/): the owner's Telegram user account, chats, conversation, composer, notices and agent actions
- [Slack](./slack/): the owner's Slack workspaces, channels, threads, composer, notices and agent actions
- [Account](./account/): the agent as the owner sees it, signing in to Alpha Cloud and the session
- [Notes](./notes/): the notes list, a note, the editor and what the agent may propose
- [Calendar](./calendar/): the agenda of the phone's and the agent's calendars, an event, its form and reviewed writes
- [Camera](./camera/): camera preview, captures, recordings and agent requests
- [Photos](./photos/): the permitted library, albums, media viewing and reviewed changes
- [Files](./files/): shared storage, folders, selections and approved changes
- [Ask Alpha](./ask/): one conversation with the resident agent
- [Clock](./clock/): alarms, timers, world clock, stopwatch, ringing alerts and agent sync
- [Reminders](./reminders/): smart views, custom lists, due dates, recurrence, priorities, due alerts, snooze, undo and agent sync
- [Sample reminders](./sample/): the sample area, which only its own journeys mount: a read, a feed, an undo window and an attempt outside
- [Text size](./sample/size.md): the second sample, which only its own journeys mount: senders, an opening that asks the phone, the phone's signals and a page-wide effect
- [Wallet](./wallet/): the wallet the agent holds: making it, what it holds, an address to be paid at, transfers reviewed and decided, and what happened
- [Maps](./maps/): search, places, directions, guidance and the map, over Cloud Maps
- [Phone](./phone/): calls, voicemail, phone details and Home cards, on an Alpha image
- [Messages](./messages/): SMS and MMS threads, composer and send, on an Alpha image
- [Contacts](./contacts/): the phone's address book and agent contact requests, on an Alpha image
- [Platform](./platform/): the world outside the page as services: the phone, the resident agent, the cloud, what the build allows and what the earlier Alpha kept
- [Image](./image/): the Alpha image, what it grants the launcher, the cable tools and the licences of what ships
- [Updates](./update/): Alpha updating itself from its channel, and each page saving its work while it does
